# The Leadership Desk - Behaviour-First Revision

Interactive GitHub Pages concept for James Fehlberg's 2027 Year 7 Year Level Coordinator EOI.

## Revision focus

This version keeps the interactive desk concept but changes the persuasive hierarchy and voice:

- behaviour leadership is now the first and most prominent evidence after the opening
- the three behaviour rules are visible together rather than buried as secondary content
- a specific exam-room de-escalation example proves regulation + accountability in practice
- the student is deliberately anonymised and no diagnosis is included
- the desk now supports the behaviour argument rather than competing with it
- evidence copy uses short human observations followed by concrete action and impact
- evidence dialogs now use What happened, What I did and Why it matters
- challenge answers are more direct, candid and conversational without becoming casual
- Quick Scan retains the behaviour centrepiece plus four essential desk examples
- coordinated leadership, referral and escalation remain explicit
- no completion counter, print control, public QR link, dormant simulator or unused capability data

## Voice

The writing is deliberately plainspoken, observant, dryly human and evidence-led. Personality is concentrated in framing lines and small observations so the application stays quick to scan.

## Deploy

1. Create or open the GitHub repository used for the EOI.
2. Upload the contents of this folder to the repository root.
3. In **Settings -> Pages**, deploy from the default branch and `/ (root)`.
4. Use `qr.html` directly if you need to generate a QR code for the final live URL.

## Privacy

The page includes `noindex, nofollow`, no analytics, no phone number or home address, and no student-identifying information. Review all content before publishing publicly.
